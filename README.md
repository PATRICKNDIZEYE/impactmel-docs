# ImpactMEL Documentation

VitePress documentation site for the ImpactMEL platform — user manual, video
walkthrough library (47 videos in `public/videos/`), setup guide, architecture,
and API reference.

```bash
npm install
npm run dev       # local preview at :5173
npm run build     # static site into .vitepress/dist
```

Videos are produced from scripts in the app workspace (`../video-studio/`) —
re-record any walkthrough there and copy the mp4 + poster here.
