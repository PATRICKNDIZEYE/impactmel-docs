# Indicator register and tracking table

Two screens under **Reports** answer the two questions people ask most often about your indicators.

- **Indicator register** — every indicator, one row each, for a period you choose.
- **Tracking table** — every indicator against every period, side by side.

Both read the same figures as a project's own PITT Report, so the three cannot disagree about a number.

---

## Indicator register

Open it from the top bar: **Reports → Indicator register**.

{{figure:indicator-register}}

### The five counts at the top

Above the table sit five tiles: the total number of indicators, then **On track**, **At risk**, **Off track** and **No data**.

Each tile is a button. Click one to filter the table to those indicators. Click it again, or click the total, to clear the filter.

### Choosing what "now" means

The first dropdown sets the scope of the Target and Actual columns:

- **Whole plan** — the life-of-plan target against everything reported so far. This is what the page opens on.
- A **year** — the targets and actuals that fall in that year.
- A named **period** — one quarter, or whatever your periods are.

When you pick a year or a period, an extra column appears on the right, **Whole plan**, so you can see the quarter and the life of the plan at once.

### Narrowing the list

Four more controls sit alongside:

| Control | What it does |
|---|---|
| **All programmes** | One programme only. Choosing one also clears any project filter that no longer applies |
| **All projects** | One project only — the list holds only projects in the chosen programme |
| **All levels** | Impact, Outcome or Output |
| **Search indicators…** | Matches name and code |

**Clear** appears once any filter is set, and resets everything.

The scope and every filter are kept in the page address. Copy the address from your browser and a colleague opens exactly the view you were looking at.

### Reading a row

| Column | What it holds |
|---|---|
| **Indicator** | Code and name, linked to the indicator. Below it: the level, the reporting frequency, how many questions are waiting to be confirmed, and whether the same definition is used in other projects |
| **Where** | The project, the programme, and the objective the indicator measures |
| **Baseline** | The starting value |
| **Target** | The target for the scope you chose, with the unit |
| **Actual** | What was reported |
| **Achieved** | Actual against target, as a percentage |
| **Status** | On track, At risk, Off track or No data — a coloured pill with a dot and a written label |
| **Reason given** | The recorded reason for a deviation. Where a row is at risk or off track with no reason, the cell offers **Add a reason**, which opens that project's tracking table |

A period with nothing reported shows as **No data**, not as zero. The two mean different things.

The foot of the table says how many indicators are listed and how many of them have a target for the chosen scope.

### Questions waiting to be confirmed

Where indicators were set up from your own documents, some points were read rather than stated outright. A band above the table says how many are waiting for your team to confirm. Open an indicator to read them and mark them right.

### Export

**Export to Excel**, top right, downloads the table as it stands. The file carries more columns than the screen does — programme, project, objective, code, indicator, level, unit, frequency, baseline, target and actual for the scope, achievement, status, reason for deviation, the whole-plan figures, open questions, and which other projects use the same definition.

The file is named after the scope you exported.

## Tracking table

Open it from the top bar: **Reports → Tracking table**.

This is the performance tracking table for the whole organisation — the table a funder or a board asks for. The per-project PITT Report answers "how is this project doing"; this one answers "how is the portfolio doing".

{{figure:tracking-table}}

### How it is laid out

Rows are grouped the way a report reads: **programme**, then **project**, then the indicators underneath.

Columns run across in pairs. Every period any indicator reports on gets a **Target** and an **Actual** column, in date order. The last pair is **Whole plan**.

The indicator column stays in place as you scroll sideways, so you never lose track of which row you are reading.

### Two controls

| Control | What it does |
|---|---|
| **By period / By year** | Whether the columns are periods or calendar years |
| **All programmes** | One programme only |

Both are kept in the page address, so a view can be sent to a colleague.

### Reasons

An actual with a recorded reason for deviation is marked with an asterisk. Hover it to read the reason. To change one, open that project's own tracking table.

The colour of an actual follows its status for that period.

### Export

**Export** downloads the whole table as an Excel file, one column pair per period, with the life-of-plan target, actual and percentage at the end.

---

## Which one to use

| You want | Use |
|---|---|
| A list of what is on track and what is not, right now | Indicator register |
| To find every off-track indicator in one programme | Indicator register, filtered |
| A target-versus-actual grid for a funder | Tracking table |
| A trend across years | Tracking table, **By year** |
| The same for one project | The project's own **PITT Report** |
